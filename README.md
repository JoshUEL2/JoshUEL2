## 🛠️ Core Engineering & Project Highlights

### 🎮 1. Technical Game Design, Shaders & Ludonarrative
*Pushing real-time visual fidelity and interactive storytelling inside Unreal Engine 5 and Twine.*

- **[REM](https://github.com/JoshUEL2/REM)**  
  *Unreal Engine 5 • HLSL • Material Graph • Ludonarrative Design*  
  A psychological surrealist narrative prototype featuring a bespoke **Kuwahara painterly post-processing filter** (directional variance edge preservation) and custom **World Position Offset (WPO) vertex displacement shaders** driven by player psychological state variables.
- **[The Quarry](https://github.com/JoshUEL2/The-Quarry)**  
  *Twine • Harlowe / JavaScript • State-Driven Narrative Architecture*  
  An interactive horror narrative engine utilizing dynamic agitation variables, hidden sanity tracking, and branching consequence algorithms to create psychological tension.
- **[Planet-Protectors](https://github.com/JoshUEL2/Planet-Protectors)**  
  *Unreal Engine 5 • Blueprint Architecture • Multiplayer Replication*  
  A multi-user cooperative sustainability prototype focused on physics-based waste sorting, procedural resource spawning, and synchronized multiplayer objectives.
- **[Playable Games on itch.io](https://joshej.itch.io/)**  
  Featuring live playable releases including *Planet Protectors*, *Rastacats* (physics racing), *Daydream Believer*, and *State Machine Showcase*.

### 🔌 2. Hardware Reverse-Engineering & Peripheral Systems
*Low-level USB HID protocol analysis, custom firmware/software plugins, and hardware telemetry.*

- **[SignalRGB-Aorus-P1200W-Plugin](https://github.com/JoshUEL2/SignalRGB-Aorus-P1200W-Plugin)**  
  *JavaScript • USB HID • Protocol Reverse-Engineering • Wireshark*  
  A custom, community-adopted hardware communication plugin for SignalRGB. Reverse-engineered USB packet structures, timing sequences, and report IDs to enable lighting synchronization for the Gigabyte Aorus P1200W power supply.
- **[SignalRGB-Plugin-Skill](https://github.com/JoshUEL2/SignalRGB-Plugin-Skill)**  
  *Python • Antigravity Skill • Developer Toolkit*  
  A comprehensive developer toolkit, API reference, and reverse-engineering guide for writing, debugging, and maintaining hardware device plugins across vendor ecosystems.
- **[HydroScreen-XC7-Compatiability](https://github.com/JoshUEL2/HydroScreen-XC7-Compatiability)**  
  *C# • .NET • Hardware Telemetry • AIO LCD Control*  
  A lightweight open-source alternative to Corsair iCUE for managing AIO cooler and custom waterblock LCD screens (including the Corsair XC7), eliminating proprietary software overhead.
- **[SignalRGB-NZXT-Triple-Gauge-Fix](https://github.com/JoshUEL2/SignalRGB-NZXT-Triple-Gauge-Fix)**  
  *HTML / CSS / JS • LCD Screen Theme Patching*  
  Engineered fixes for background opacity, frame transparency, and sideloading defects in SignalRGB's NZXT Triple Gauge LCD theme.
